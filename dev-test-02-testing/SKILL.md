# 测试-02: 系统测试

基于测试用例执行系统级测试，验证功能正确性、性能达标和系统稳定性。

## 触发条件

- 代码审查通过，可以开始测试
- 用户提到 "系统测试"、"集成测试"、"测试执行"、"跑测试"
- 需要验证系统是否满足发布标准

## 执行步骤

### Step 1: 测试环境部署

```markdown
## 测试环境部署检查

### 环境准备
- [ ] 测试环境已部署最新代码
- [ ] 数据库已初始化测试数据
- [ ] 第三方服务Mock已配置
- [ ] 测试账号已创建
```

### Step 2: 功能测试执行

```markdown
## 功能测试执行

### 执行记录
| 用例编号 | 用例标题 | 执行结果 | 实际结果 | 截图 | 执行人 |
|---------|---------|---------|---------|------|--------|
| TC-001 | | ✅通过 | | | |
| TC-002 | | ❌失败 | [实际行为描述] | [链接] | |
```

### Step 3: 缺陷报告

```markdown
## 缺陷报告

### BUG-001: [缺陷标题]

| 项目 | 内容 |
|------|------|
| 缺陷编号 | BUG-001 |
| 严重程度 | 🔴致命 / 🟡严重 / 🔵一般 / ⚪轻微 |
| 优先级 | P0 / P1 / P2 |
| 所属模块 | [模块名] |
| 关联用例 | TC-XXX |

**复现步骤**:
1. [操作步骤]
2. [操作步骤]
3. [操作步骤]

**预期结果**: [应该发生什么]

**实际结果**: [实际发生了什么]
```

### Step 4-Step 6: 接口/性能/安全测试

执行并记录各类型测试结果。

### Step 7: 测试报告

```markdown
## 测试报告

### 测试结论

| 优先级 | 通过率 | 结论 |
|--------|--------|------|
| P0 | X% | ✅达标(100%) / ❌未达标 |
| P1 | X% | ✅达标(≥95%) / ❌未达标 |
```

## 发布标准

| 条件 | 标准 |
|------|------|
| P0 用例通过率 | 100% |
| P1 用例通过率 | ≥ 95% |
| 致命缺陷 | 0个未修复 |
| 严重缺陷 | 0个未修复 |
| 性能指标 | 满足 PRD 要求 |
| 安全漏洞 | 无高危 |

## 输出物

- 功能测试执行记录
- 缺陷报告
- 接口测试结果
- 性能测试报告
- 安全测试报告
- 测试总结报告

## 质量检查清单

- [ ] 所有 P0 用例已执行
- [ ] 失败用例有缺陷报告
- [ ] 性能测试已完成
- [ ] 安全测试已完成
- [ ] 测试报告已输出
