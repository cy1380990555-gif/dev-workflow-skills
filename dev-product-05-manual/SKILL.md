# 产品-05: 操作说明手册编写

系统测试通过后，基于 PRD、UI 设计和测试结果，编写面向用户和管理员的操作文档，**必须包含系统页面截图**。

## 触发条件

- 系统测试通过，准备上线
- 用户提到 "操作手册"、"使用说明"、"用户手册"、"写文档"
- 需要为终端用户提供操作指引

## 执行步骤

### Step 1: 确定文档受众和范围

```markdown
## 文档规划

### 目标读者
| 读者类型 | 角色描述 | 关注内容 |
|---------|---------|---------|
| 普通用户 | 日常使用系统 | 操作指南、FAQ |
| 管理员 | 管理系统配置 | 配置指南、管理功能 |
| 运维人员 | 部署和维护系统 | 部署文档、故障排查 |
```

### Step 2: 快速入门编写

包含注册登录、首次使用引导，每个步骤附截图。

### Step 3: 功能操作指南

按模块编写，每个功能包含操作步骤和页面截图：

```markdown
## [模块名称]

### [功能名称]

**功能说明**: [一段话描述这个功能做什么]

![功能页面](截图路径)

**操作步骤**:
1. 在左侧导航栏点击「[菜单名]」
2. 在页面中点击「[按钮名]」
3. 在弹出的表单中填写
4. 点击「确认」提交

> 💡 提示：[使用技巧]
> ⚠️ 注意：[注意事项]
```

### Step 4: 管理员指南

包含系统配置、用户管理、数据管理、日志查看，每个步骤附截图。

### Step 5: FAQ 编写

包含账号相关、功能相关问题解答。

### Step 6: 术语表

专业术语解释和缩写对照。

## 页面截图规范

- **来源**：从测试环境/生产环境中截取真实系统页面
- **范围**：每个功能操作至少 1 张页面截图，关键步骤单独截图
- **标注**：在截图上用红框标注操作区域，编号对应操作步骤
- **状态**：核心页面需包含正常状态截图
- **格式**：PNG 格式，分辨率 1440px 宽度
- **隐私**：截图中的真实用户数据需脱敏处理

## 输出物

- 快速入门指南（含截图）
- 功能操作指南（按模块，含截图）
- 管理员指南（含截图）
- FAQ 和错误码表
- 术语表
- 页面截图集

## 质量检查清单

- [ ] 所有 P0 功能有操作指南
- [ ] 每个操作步骤有对应页面截图
- [ ] 截图标注清晰，操作区域已标注
- [ ] 操作步骤可被非技术人员理解
- [ ] 常见错误有解决方案
- [ ] 管理员操作已覆盖
- [ ] 截图中无敏感数据泄露
- [ ] 非项目成员试读验证通过
