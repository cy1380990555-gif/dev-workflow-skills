# 产品-06: 上线发布

管理软件的发布和部署，确保平稳上线，包含回滚方案和监控告警。

## 触发条件

- 系统测试通过，操作手册完成，准备上线
- 用户提到 "上线"、"发布"、"部署"、"deploy"、"release"
- 需要将系统部署到生产环境

## 执行步骤

### Step 1: 发布准备检查

逐项确认发布前置条件：

```markdown
## 发布准备检查清单

### 代码与测试
- [ ] 所有 P0 功能代码已合并到发布分支
- [ ] 系统测试全部通过
- [ ] 无 🔴 致命和 🟡 严重未修复缺陷
- [ ] 代码审查已通过
- [ ] 回归测试通过

### 文档与配置
- [ ] 操作说明手册已完成
- [ ] 配置文件已更新（生产环境）
- [ ] 数据库变更脚本已准备
- [ ] 环境变量已确认
- [ ] 发布说明（Release Notes）已编写

### 运维与监控
- [ ] 生产环境已准备
- [ ] 监控告警已配置
- [ ] 回滚方案已准备并验证
- [ ] 日志收集已配置

### 人员与沟通
- [ ] 发布时间窗口已确认
- [ ] 相关人员已通知
- [ ] 值班人员已安排
- [ ] 应急联系方式已确认
```

### Step 2: 编写发布计划

```markdown
## 发布计划

### 基本信息
| 项目 | 内容 |
|------|------|
| 发布版本 | v1.0.0 |
| 发布时间 | YYYY-MM-DD HH:MM |
| 预计耗时 | X分钟 |
| 发布负责人 | |

### 发布步骤
| 步骤 | 操作 | 负责人 | 预计耗时 | 验证方式 |
|------|------|--------|---------|---------|
| 1 | 备份生产数据库 | | 5min | 备份文件存在 |
| 2 | 停止服务 | | 2min | 服务状态为停止 |
| 3 | 执行数据库迁移 | | 5min | 迁移脚本执行成功 |
| 4 | 部署新版本 | | 10min | 版本号正确 |
| 5 | 启动服务 | | 2min | 健康检查通过 |
| 6 | 冒烟测试 | | 10min | 核心功能正常 |
| 7 | 通知完成 | | 1min | 通知已发送 |
```

### Step 3: 编写回滚方案

```markdown
## 回滚方案

### 回滚触发条件
- 冒烟测试核心功能失败
- 上线后 30 分钟内错误率 > 1%
- 上线后关键业务流程不可用
- 数据一致性问题

### 回滚步骤
| 步骤 | 操作 | 预计耗时 |
|------|------|---------|
| 1 | 停止服务 | 2min |
| 2 | 恢复旧版本代码 | 5min |
| 3 | 恢复数据库备份 | 10min |
| 4 | 启动服务 | 2min |
| 5 | 验证回滚成功 | 5min |

**预计回滚耗时**: XX分钟
```

### Step 4: 灰度发布方案（如适用）

```markdown
## 灰度发布方案

| 阶段 | 流量比例 | 持续时间 | 观察指标 | 通过条件 |
|------|---------|---------|---------|---------|
| 灰度1 | 5% | 2小时 | 错误率、延迟 | 错误率<0.5% |
| 灰度2 | 20% | 4小时 | 错误率、延迟 | 错误率<0.5% |
| 全量 | 100% | - | - | - |
```

### Step 5: 监控告警配置

```markdown
## 监控告警

### 业务指标监控
| 指标 | 正常范围 | 告警阈值 | 通知方式 |
|------|---------|---------|---------|
| 核心功能成功率 | >99% | <98% | 短信+群通知 |
| 日活/交易量 | [基线] | 下降>30% | 群通知 |

### 系统指标监控
| 指标 | 正常范围 | 告警阈值 | 通知方式 |
|------|---------|---------|---------|
| CPU使用率 | <70% | >85% | 短信 |
| 内存使用率 | <80% | >90% | 短信 |
| API响应时间P95 | <500ms | >1s | 群通知 |
| 错误率 | <0.5% | >1% | 短信+群通知 |
```

### Step 6: 执行发布

按发布计划逐步执行，每步记录结果。

### Step 7: 发布后验证

```markdown
## 发布验证

### 冒烟测试
| 功能 | 验证结果 |
|------|---------|
| 登录 | ✅/❌ |
| 核心功能1 | ✅/❌ |
| 核心功能2 | ✅/❌ |
| 数据查询 | ✅/❌ |
```
