# 测试-01: 测试用例编写

基于 PRD 和架构设计，编写全面的测试用例。

## 触发条件

- PRD 和架构设计已完成，需要编写测试用例
- 用户提到 "测试用例"、"测试计划"、"写用例"、"QA"
- 可与代码编写并行进行

## 执行步骤

### Step 1: 测试计划

```markdown
## 测试计划

### 测试范围
| 范围 | 说明 |
|------|------|
| 包含 | [功能模块列表] |
| 不包含 | [不在测试范围的] |

### 测试类型和策略
| 测试类型 | 占比 | 工具 | 说明 |
|---------|------|------|------|
| 功能测试 | 50% | 手工 | 核心业务流程验证 |
| 接口测试 | 20% | Postman/自动化 | API 契约验证 |
| 异常测试 | 15% | 手工 | 边界和异常场景 |
| 性能测试 | 10% | JMeter/k6 | 性能指标验证 |
| 安全测试 | 5% | OWASP ZAP | 基础安全扫描 |
```

### Step 2: 功能测试用例

```markdown
## 功能测试用例

### TC-001: [用例标题]

| 项目 | 内容 |
|------|------|
| 用例编号 | TC-001 |
| 所属模块 | [模块名] |
| 优先级 | P0/P1/P2 |
| 关联需求 | REQ-XXX |
| 前置条件 | [执行前需要满足的条件] |

**测试步骤**:
| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | [操作描述] | [预期系统行为] |
| 2 | | |
```

### Step 3: 接口测试用例

覆盖正常场景、参数边界、权限控制。

### Step 4: 异常和边界测试

包含网络异常、并发场景、数据边界。

### Step 5: 非功能测试用例

包含性能测试场景、安全测试场景、兼容性测试矩阵。

## 输出物

- 测试计划
- 功能测试用例
- 接口测试用例
- 异常和边界测试用例
- 非功能测试场景
- 测试数据准备

## 质量检查清单

- [ ] 所有 P0 功能有测试用例
- [ ] 接口测试覆盖正常+异常+权限
- [ ] 边界条件已覆盖
- [ ] 性能测试场景有明确指标
- [ ] 安全测试场景已定义
- [ ] 测试数据已准备
- [ ] 用例已与产品和开发评审
